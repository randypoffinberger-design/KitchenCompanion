# Kitchen Companion v0.12.4

## Shared shopping lists

- Share unchecked shopping items as a dedicated `.kcshopping` file through the device share sheet.
- Include clean item names, quantities, recipe sources, stores, and shopping groups.
- Import a shopping list from another Kitchen Companion user directly from the Shopping List screen.
- Merge matching open ingredients without replacing existing items, checked items, or learned preferences.
- Add imported store names without removing the receiving profile's stores.
- Prevent entries from duplicating when the same shared file is imported again.
- Validate file structure and size before import.
- Create a verified safety checkpoint before changing the receiving list and roll back failed imports.
